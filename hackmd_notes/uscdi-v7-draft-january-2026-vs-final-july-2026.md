# USCDI v7: Draft (January 2026) vs. Final (July 2026)

Generated by Claude

Comparison of every data class and data element that was newly proposed in Draft USCDI v7, plus changes made in the final publication.

**Sources:**
- *United States Core Data for Interoperability*, Draft Version 7, January 2026 (ASTP)
- *United States Core Data for Interoperability*, Version 7, July 2026 (ONC)

## 2. New data classes proposed in Draft v7

| Data class | Change in final |
|---|---|
| Adverse Events | **Class definition revised.** Final adds an exclusions paragraph carving out patient safety analyses, internal risk management documentation, and patient safety work product as defined under the Patient Safety and Quality Improvement Act of 2005 (42 U.S.C. 299b-21 et seq.) and 42 CFR part 3. States the class is not intended to define data elements for exchange of PSO investigations, safety reviews, or facility-level reporting activities. |
| Healthcare Information Attributes | Class definition unchanged. Two of its four member elements were renamed: Diagnostic Report Date → Diagnostic Report Date and Time; Performance Time → Performance Date and Time. |

## 3. Added in final, not present in Draft v7

| Element | Data class | Notes |
|---|---|---|
| Specimen Collection Date and Time | Laboratory | The only genuinely new data element between draft and final. Definition: "Date and time when the specimen was obtained." Note that the draft's Performance Time definition listed "laboratory specimen collection time" among its examples; the final drops that example and gives specimen collection its own element in the Laboratory class. |

## 4. Collateral changes to pre-existing elements and classes

| Item | Change |
|---|---|
| Encounter Time | **Renamed** to Encounter Date and Time. Definition adjusted ("Date/times related to an encounter" → "Dates and times related to an encounter"). |
| Performance Time | **Renamed** to Performance Date and Time. Definition adjusted ("Time and/or date a care activity is performed" → "Date and time a care activity is performed"). Example "laboratory specimen collection time" removed. |
| Unique Device Identifier | **Definition revised**: presence of production identifiers (PI) is now conditioned on device risk class. |
| Medical Devices (class) | **Definition replaced** with an FD&C Act-style definition: instrument, apparatus, machine, equipment, implant, software, hardware, or related component or accessory intended to diagnose, treat, cure, mitigate, or prevent disease, or to affect the structure or function of the body. |

A consistent naming convention emerges in the final: date/time elements are normalized to the pattern "<Concept> Date and Time."

## 6. Notes for US Core

- **Accommodation**: the SNOMED CT binding present in the draft was removed in final. Any planned value set binding should be revisited.
- **Patient Identifier**: the uniqueness assertion was dropped from the definition, loosening what conformance language can claim.
- **Specimen Collection Date and Time**: new in final and lands in territory US Core already handles via `Specimen.collection.collected[x]`.
- **Reason Not Performed**: usage note moved from "Should be included with" to "Include with at least," which reads closer to a SHALL-flavored expectation across procedure, immunization, and medication.
- **Tobacco and Nicotine Product Use**: the rename plus the explicit exclusion of prescribed nicotine replacement therapies affects any value set scoping inherited from the Smoking Status lineage.
- **Adverse Events**: the new PSQIA exclusions paragraph is a scope boundary worth mirroring in narrative if US Core profiles this class.

## 7. ONC's own change tables (Final v7, pp. 49)

For cross-checking, the final publication's "Changes between Draft USCDI v7 and USCDI v7" section lists:

- **New Data Elements**: Specimen Collection Date and Time
- **Data Element Names Revised**: Adverse Event Condition; Diagnostic Report Date and Time; Encounter Date and Time; Performance Date and Time; Tobacco and Nicotine Product Use
- **Data Element Definitions Revised**: Accommodation; Adverse Event Condition; Adverse Event Outcome; Appointment; Condition Status; Health Insurance Coverage Period; Healthcare Agent; Immunization Record Source; Immunization Status; Medical Device Order; Medication Administration; Medication Dispense Quantity; Nutrition Order; Patient Identifier; Reason Not Performed; Referral Order; Tobacco and Nicotine Product Use; Unique Device Identifier
- **Applicable Standard Added**: Specimen Collection Method
- **Applicable Standard Removed**: Accommodation
- **Data Class Definition Revised**: Adverse Events; Medical Devices

Two edits observed in the source text are **not** reflected in ONC's change table: the editorial revisions to Diagnostic Imaging Reference ("The information" → "Information") and Procedure Status ("The status" → "Status").
