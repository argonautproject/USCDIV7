# LOINC 88028-6 — Tobacco use panel

**Status:** Active
**LOINC Version:** 2.82
**Source:** <https://loinc.org/88028-6>

## Term Description

This panel contains LOINC terms to describe tobacco use and associated information for both smoked and smokeless tobacco.
